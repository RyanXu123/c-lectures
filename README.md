# C 语言讲义 · 从零到单片机（2026 秋）

写给一个机电专业大一学生的 C 语言讲义。**一讲一个文件**，结构固定：

> 人话讲概念 → 看代码 → 动手改 → 三道小测

规矩三条：

1. 代码一律先在本机编过、跑过才写进讲义（MinGW-W64 gcc 16.1.0）；跑崩的对照件连退出码一起贴出来。
2. 讲义里出现任何一个没学过的名字或写法，都要先有一段"这是什么"，不许糊过去。
3. 每讲末尾有《参考了什么》表：ISO C 标准、Linux man-pages、K&R、翁恺 / 江协科技等课程分 P，各换来了什么，写清楚。

配套的**代码仓库**（讲课示例、作业、考核题）：<https://github.com/RyanXu123/1>

## 怎么用

- 按编号顺序读。每讲的"动手"部分别跳过——那些是要自己在机器上敲出来、编译跑一遍的。
- 卡住先看同号《补充》篇；补充篇都是被问出来才补的，专治"讲义里没讲过但你已经在用"的东西。
- 学习进度记在 `C语言十二讲_教学大纲.md` 里，别拿正文的规划稿去推"这讲上没上过"。
